# Gulayn, редизайн лендинга

Next.js (App Router) + Tailwind CSS 4 + Motion. Шрифт Geist.

## Запуск

```bash
npm install
npm run dev
```

Откроется на http://localhost:3000

## Что внутри

Блоки страницы по порядку:

- `header.tsx` — шапка-чёлка: меню, язык, тема, вход
- `hero.tsx` — первый экран: заголовок, промпт-бар, бегущая строка логотипов
- `models-bento.tsx` — нейросети по задачам
- `prompt-gallery.tsx` — «Как слова становятся кадром», разбор промптов
- `how-to-start.tsx` — три шага с мини-интерфейсами
- `why-gulayn.tsx` — шесть причин на фактах
- `savings-calculator.tsx` — калькулятор выгоды против тарифа «Про»
- `pricing.tsx` — тарифы: личные и командные, месяц и год
- `faq.tsx` — частые вопросы, открыт один ответ
- `cta.tsx` — финальный призыв
- `footer.tsx` — подвал
- `raffle-card.tsx` — карточка розыгрыша в углу: после прокрутки до тарифов или по ссылке #raffle, после обновления страницы появляется снова

Остальное:

- `reveal.tsx` — анимации появления блоков
- `src/data/content.ts` — тексты, промпты, нейросети, тарифы, вопросы
- `public/logos` — логотипы (svgl.app и LobeHub Icons, MIT)
- `public/images` — временные фото с Unsplash, заменить на реальные генерации; iPhone взят с gulayn.ru

Темы: тёмная по умолчанию и светлая, переключатель в шапке и подвале, выбор запоминается. Ссылка сразу на светлую: `?theme=light`. Цвета задаются переменными в `globals.css`, чёлка всегда тёмная (класс `.theme-dark`).

Пока не сделано: английская версия (кнопка языка есть, логики нет).

## Деплой на GitHub Pages

Сайт статический: `npm run build` собирает его в папку `out`. Публикацию делает workflow `.github/workflows/deploy.yml` при каждом пуше в `main`.

Один раз в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Сайт откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`. Префикс адреса workflow подставляет сам через `NEXT_PUBLIC_BASE_PATH`, поэтому картинки в коде подключаются через `asset()` из `src/lib/asset.ts`.

Ссылки на регистрацию и вход пока заглушки (`#register`, `#login`): это работа для портфолио.
